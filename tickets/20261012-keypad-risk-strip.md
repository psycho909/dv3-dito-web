## Goal

記牌時不需捲動：開局確認、本局點數與已抽石頭、建議與安全率／爆牌率、點數鍵、撤銷／完成本局／開始新局都在第一個螢幕內；爆牌風險高時明顯提醒。

## Scope

### A. 單螢幕記牌區（首屏）

- 目標視窗：375×667、390×844（手機）與 1280×720（桌機）。頁面載入後不捲動即可完整看見下列元素（boundingBox 完全落在視窗內）：
  - 未開始：「確認從 52 顆開始記錄」。
  - 進行中：本局點數與等級、已抽石頭、剩餘 N／52（精簡一行，可點開牌池明細）、建議一行（例如「建議再抽」／「建議停手」，詳細比較可留在下方）、安全率／爆牌率提示、十個點數鍵、撤銷輸入、完成本局。
  - 本局完成：本局結果摘要（等級與得分一行）、開始新局按鈕（放在原「完成本局」位置附近）。
- 首屏以外的內容依序移到記牌區下方：再抽 1 顆的五級分布、本局最終等級預估、核對剩餘、逐點數明細、歷史與修正、雲端備份狀態與 GitHub 登入、備份與資料管理、頁尾。標題列精簡為一行（工具名稱＋必要狀態），雲端狀態若需在首屏只能是一行小字。
- 不刪除任何現有功能或資訊，只調整順序與精簡呈現；對話框、抽屜、焦點管理與鍵盤操作維持。
- 已抽石頭很多時（例如 A、A、2、3…），首屏高度仍不得把點數鍵或完成按鈕推出視窗（可水平捲動或縮小石頭）。

### B. 鍵盤風險提示

- 安全率／爆牌率顯示在「記錄遊戲剛抽到的石頭」區（點數鍵正上方），自機率區移除原位置避免重複；數值沿用 `calculateNextDraw`，計算不變。
- 閘門同原本：只有 SYNCED 且可計算時顯示數字；推定週期標「推定」；UNSYNCED、未開始、空牌池顯示佔位與原因。
- 三級警示（Claude Code 預設、可逆）：爆牌率 < 30% 一般；30%～< 50%「注意」；≥ 50%「高風險」。文字標籤＋邊框／icon，不只靠顏色，對比符合既有標準；reduced-motion 無動畫。
- 預留固定高度：數值出現／消失／警示級別改變時點數鍵不位移。
- aria：例如「下一顆安全率 X%，爆牌率 Y%，高風險」，更新不搶焦點。

### D. 設計規劃（Owner 2026-10-12 核准「依照建議去執行」）

- 沿用 DESIGN.md 鍛造台契約：既有色票 token、系統字＋Dito Forge Digits、六角石頭片、5×2 鍵盤（鍵高 ≥ 60px）、字級 13／16／20／28＋分數 56px；不新增色票與字型。
- 首屏為「一整塊連續鐵砧台面」：標題列、分數板、風險熱條、點數鍵、動作列同屬一個面板，以 seam 細線分隔，不再拆成多張卡片。手機 375×667 首屏內容預算約 500px（保留瀏覽器工具列空間）。
- 標題列（約 40px）：精簡工具名稱、雲端狀態一個小字、「剩 N/52」（可點開牌池明細）。
- 分數板：最大字為分數「17 /21」，旁邊等級與得分；右側一行「建議停手／建議再抽」；下方已抽石頭單行，過多時橫向捲動，不推擠下方。
- 風險熱條焊在點數鍵上緣（全寬）：填滿比例＝爆牌率；< 30% heat-normal 一般、30%～< 50% heat-good「注意」、≥ 50% heat-burst＋斜紋「高風險」；旁以小字標「爆牌 X%」與安全率數字。唯一動態為填滿變化 ≤ 150ms，reduced-motion 無動態。
- 三種狀態共用同一位置與高度：未開始＝分數板位置放「確認從 52 顆開始記錄」主按鈕、熱條顯示「開始記錄後顯示」、點數鍵停用但佔位；完成＝分數板顯示「本局 GREAT，得 50 分」、熱條顯示下局爆牌預估、動作列主按鈕為「開始新局」。
- 桌機 1280×720：左欄為首屏台面，右欄為五級分布、本局等級預估、核對；帳號、歷史、資料管理在兩欄下方。
- 首屏以下的分析區同樣改為平面＋seam 細線分隔，移除一張張相同卡片的外觀；對話框與抽屜維持既有層級。
- 文案：動詞開頭；移除「·」中點串接（例：「本局等級：GREAT · 得分 50 分」→「本局 GREAT，得 50 分」）；風險只陳述事實；未同步寫明原因與下一步。
- 同步更新 `DESIGN.md`（Layout、Components）與 `docs/UIUX Design.md`。
